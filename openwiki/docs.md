# Supplementary Documentation

The `docs/` directory contains additional guides and references that complement the stack-specific documentation and the operational workflows described elsewhere in this wiki.

## Contents

Currently, the `docs/` directory includes:

- **SOPS, age, File Watcher, Komodo, and Unraid** (`docs/sops-age-komodo.md`):  
  A detailed guide on setting up the SOPS/age encryption workflow with File Watcher in VS Code, including installation steps for macOS and Windows, and how Komodo uses encrypted environment files.

- **GitHub Workflows** (`docs/github-workflows/`):  
  Directory containing documentation or examples related to GitHub Actions workflows used in the repository (if any).

- **Agents** (`docs/agents/`):  
  Directory possibly containing documentation for AI agents or automation scripts (if any).

- **Research** (`docs/research/`):  
  Directory for research notes or experimental setups (if any).

- **Assets** (`docs/assets/`):  
  Directory for images, diagrams, or other assets used in documentation.

## How to Use

Refer to the specific files in `docs/` for in-depth guidance on particular topics. For example, the SOPS/age guide is the primary reference for setting up encrypted environment variables.
