# Files

- [Edge and Networking Domain](edge-and-networking.md) - Documents the edge and networking stack including Traefik for ingress, Cloudflared for tunneling, AdGuard Home with Unbound for DNS filtering and resolution, and CrowdSec for security telemetry and banning.
- [Media Domain](media.md) - Documentation of the media stacks (Plex, Radarr, Sonarr, Prowlarr) responsible for media acquisition, indexing, and streaming in the homelab.
- [Homelab Architecture Overview](overview.md) - Provides a high-level overview of the homelab architecture, including the main domains (edge/networking, identity/access, media, utility) and their interactions.
- [Utility and Infrastructure Domain](utility-and-infrastructure.md) - Documentation of utility and infrastructure stacks providing messaging (Mosquitto), container storage (Registry), monitoring (Uptime Kuma), and backup (CloudBerry Backup) services for the homelab.
