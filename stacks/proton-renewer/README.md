# Proton Renewer

> Rider that renews the persistent Proton WireGuard profiles in place before they expire, so the keys the VPN stacks hold stay valid

## Stack Role

This stack directory stores the `compose.yaml`, `README.md`, and tracked `.env.example` for `proton-renewer`.
